# FlowNote 역할별 매뉴얼

## 기준

- 기준일: 2026-08-15
- 적용 대상: 현재 연구 프로토타입의 메뉴, 화면과 운영 스크립트

이 폴더는 설계 설명이 아니라 실제 역할별 업무 순서를 제공한다. UX가 변경되면 화면 이름, 버튼 이름, 선행 조건과 실패 후 조치를 함께 갱신한다.

## 공통 사용 원칙

1. 운영에서는 승인된 HTTPS 서버와 설치형 앱만 사용한다.
2. 연결 오류를 로컬 서버, HTTP 또는 다른 계정으로 우회하지 않는다.
3. 실패 화면에 `보존됨`, `전송 대기`, `부분 성공`, `충돌`이 표시되면 DB·Files·outbox를 삭제하지 않는다.
4. 문서 등록은 공개가 아니다. 검토와 공개 승인 절차를 거친다.
5. FieldComment 원문을 보고서 문장처럼 다듬어 입력하지 않는다. 현장에서 관찰한 사실을 짧게 남긴다.
6. 비밀번호, 토큰, 인증서, 개인키, 실제 고객 자료와 운영 서버 경로를 Git 문서에 기록하지 않는다.
7. 매뉴얼의 예시 식별자는 실제 고객명·설비명·사용자 ID가 아니다.

## 문서와 운영 기록의 구분

- 이 매뉴얼은 현재 화면을 사용하는 방법을 설명한다.
- 실제 설치 주소, 자산 ID, 승인자와 연락망은 접근 통제된 현장 운영대장에 기록한다.
- 테스트 실행 로그, SQLite, 입력·출력 파일과 렌더링 결과는 누적 검증 기록이므로 삭제하지 않고 Git에서만 제외한다.
- 운영 완료 판정은 [배포 기준](../deployment.md)과 [파일럿 기준](../pilot-rehearsal.md)을 따른다.

## UX 변경 때 갱신할 항목

- 메뉴와 버튼의 정확한 한글 이름
- 역할별 첫 업무 순서
- 입력 필수값과 저장 시점
- 실패했을 때 보존되는 데이터
- 자동 재시도와 수동 재시도의 범위
- 화면 캡처와 버전 정보
- 관련 테스트와 파일럿 시나리오

화면이 바뀌어도 문서 원천, FieldComment 원천, 보고서 근거, 감사 이력과 무손실 재시도 원칙은 임의로 축소하지 않는다.
