# 2026-06-23 작업 기록

이 문서는 과거 작업 기록을 현재 코드 기준 용어로 정리한 것이다. 현재 제품 기준은 상위 문서인 [제품 개요](../product-overview.md), [시스템 맵](../system-map.md), [데이터 모델](../data-model.md)을 따른다.

## 정리된 내용

- FlowNote를 문서관리와 현장 지식 축적을 함께 다루는 사내 서버형 제품으로 정리했다.
- 초기 범위는 문서 파일, 문서 버전, 변경 사유, 로그인 권한, 현장 단말기 뷰어, FieldComment, 작업순서, 보고서 보조에 둔다.
- 운영 provider를 통한 실제 외부 AI 검색·요약과 작업 조언은 축적된 데이터를 활용하는 후속 계층으로 둔다. 현재 구현은 서버 `ai_search_candidates` 근거 후보 재생성·목록·품질 점검, 독립 승인 사례와 불변 dataset version 기반 회귀 평가, 실제 익명 현장 24칸 독립 표본 검토·제3 합의 API, WPF 근거 후보 점검·`AI 정답셋`, `/api/v1/ai/queries`의 기본 비활성 안전장치·응답 검증, `/api/v1/ai-operations` 운영 제어까지다.
- 클라이언트는 Windows WPF와 승인된 Android 현장 단말의 설치형 앱을 기준으로 하고, 브라우저 직접 접근은 기본 운영 방식으로 두지 않는다.

## 현재 코드와의 관계

- Windows 앱은 로컬 SQLite에 문서, 버전, FieldComment 원천, 알림, 보고서 초안, 사용자 계정과 보존 동기화 큐를 관리한다. 작업순서 로컬 row는 읽기 캐시·초안이며 최종 변경은 FastAPI 서버 snapshot과 `board_revision`을 사용한다.
- FastAPI 서버는 SQLite와 서버 로컬 파일 저장소를 기준으로 문서, FieldComment, 작업순서, 보고서 API와 instance/epoch manifest·관리자 승인형 reconciliation을 제공한다.
- Android 앱은 승인 단말 로그인, 공개 문서 목록·상세와 PDF/이미지/UTF-8 TXT 앱 내부 보안 열람, Keystore 보호 FieldComment/사진 outbox, foreground service 채널 알림과 인수인계 확인을 제공한다.
- 서버 계정 수명주기와 강제 비밀번호 변경, 승인 단말 관리, controlled copy, 문서 revision·충돌 작업함, WPF 알림 cursor 보존, FieldComment 원천 불변·단계형 검토/품질 작업함, 도메인별 mutation receipt와 서버 복구 재결합은 2026-07-27 현재 구현 범위다.
- 문서 구조는 고객이 정하는 폴더 체계를 따른다. BOM 문서 구조는 예시이며 기본 강제 구조가 아니다.
