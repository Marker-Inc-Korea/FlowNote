# Android App

`apps/android/`는 FlowNote Android 현장 단말 클라이언트 영역이다. 아직 Android 프레임워크 스캐폴딩은 추가하지 않았다.

## 역할

- 승인된 현장 태블릿 또는 러기드 단말에서 사용한다.
- 공개 문서 열람, QR/검색 기반 문서 접근, FieldComment 작성, 사진 기록, 신호등식 상태 기록을 담당한다.
- 인수인계 작성, 수신 확인, 후속 FieldComment 연결을 담당한다.
- 라인, 설비, 공정, 작업조, 작업내역, 인수인계 기준 업무 채널 알림을 표시한다.
- Windows WPF의 채널 수신함, 채널 관리, 인수인계 확인 현황 화면과 같은 서버 채널 데이터를 공유한다.

## 범위 기준

- 개인 휴대폰 기본 배포는 초기 기준이 아니다.
- 개인 메신저 수집이나 사내 메신저 전체 대체 기능을 만들지 않는다.
- 알림과 짧은 응답은 문서, FieldComment, 작업순서, 작업내역, 인수인계 같은 원천 데이터에 연결한다.
- 장기 원천 데이터는 FastAPI 서버와 서버 SQLite, `storage/`에 남긴다. Android 로컬 저장은 네트워크 불안정 구간의 임시 보관과 재전송을 위한 범위로 제한한다.

## 구현 전 확인할 사항

- Android 기술 스택과 최소 OS 버전
- 단말 등록과 현장별 배포 방식
- 사내망 접속, HTTPS, 인증서, 서버 주소 설정 방식
- 알림 전달 방식: 외부 푸시 서비스, 사내망 polling, WebSocket 중 선택
- 오프라인 임시 저장 암호화와 재전송 정책
